# Museum Heist: Midnight Shadows

> **2D Top-Down тактична стелс-гра**, розроблена на рушії **Godot Engine 4.x** (GDScript) із підтримкою запуску у веб-браузері (HTML5 / WebAssembly).

 **[Повний Game Design Document (GDD) та опис статусу проєкту](docs/)**

---

## Про гру

**Museum Heist: Midnight Shadows** — це стелс-екшен з видом зверху. Гравець бере на себе роль професійного злодія, який проникає до міського історичного музею після закриття. 

**Головна мета:** проаналізувати маршрути нічних охоронців, сховатися за колонами та інтер'єром від світла їхніх ліхтарів, відволікати патрульних монетками, деактивувати захисну систему через розподільчий щиток, викрасти цінну реліквію («Око Фараона») та непомітно дістатися запасного виходу.

## Керування (Controls)

| Клавіша | Дія | Опис |
| :--- | :--- | :--- |
| **W, A, S, D** | Пересування | Базовий рух персонажа залами музею |
| **Shift** *(утримувати)* | Безшумне підкрадання | Сповільнює швидкість, зменшує радіус чутності кроків |
| **Q** | Кидок монетки | Відволікання охоронців шумом у напрямку курсора (3 монетки на спробу) |
| **E** *(натиснути / утримувати)* | Взаємодія | Вимкнення щитка сигналізації, відкриття вітрини з індикатором прогресу, вихід |
| **Курсор миші** | Погляд та прицілювання | Орієнтація персонажа та напрямок кидка монетки |
| **Esc** | Пауза | Меню паузи з поточною статистикою (`Resume` / `Restart` / `Main Menu`) |

### Debug-клавіші (для тестування)
* `1` — активувати щиток | `2` — отримати артефакт | `3` — миттєва перемога | `4` — миттєва поразка | `0` — перезапуск | `9` — скинути рекорди.

## Ключові механіки та фічі

* **Просунутий AI охоронців:**
  * **Динамічні конуси зору (60°, `RayCast2D`):** Стіни та колони блокують промені ліхтарика, формуючи сліпі зони; охоронці періодично оглядаються на 180°.
  * **Кінцевий автомат станів (`State Machine`):** Три режими поведінки зі своєю швидкістю руху — патрулювання (`Patrol`, 80 px/s), перевірка/пошук (`Investigate`, 110 px/s) та тривога/переслідування (`Alarm`, 185 px/s) із запам'ятовуванням останньої позиції гравця та обходом перешкод по сітці.
  * **Дві ролі охорони:** *Патрульні* (залишають маршрут для перевірки джерел шуму) та *Постові* (повертаються у бік шуму, залишаючись на посту).
  * **Слух та відволікання:** Охоронці чують звичайні кроки (навіть позаду себе) та реагують на кинуті гравцем монетки (`Q`).
* **Подвійна система виявлення:**
  * **Шкала підозри (Detection Meter):** Заповнюється залежно від відстані до охоронця; при втраті зорового контакту поступово спадає. При 100% — поразка.
  * **Миттєве захоплення:** Наближення охоронця до гравця на відстань 50 px без перешкод призводить до миттєвого арешту.
* **Послідовний геймплейний цикл (`GameManager` & `SceneManager`):** Вітрина відкривається лише після знеструмлення щитка; вихід спрацьовує лише за наявності артефакту.
* **Атмосферний UI та система рекордів:**
  * Анімоване головне меню (нічне місто, дощ, світло ліхтаря у вікні музею, емблема «Око Фараона») з єдиною темою оформлення (шрифти *Chakra Petch* + *Barlow*).
  * Інформативний HUD (поточна ціль з іконкою, шкала виявлення, таймер, лічильник монеток, підказки).
  * **Екран результатів (Run Report):** Підсумок часу, пікового виявлення, монеток, збереження найкращого часу (`NEW BEST`) та видача штампа **`CLEAN`**, якщо рівень підозри не перевищив 40%.

## Технологічний стек та структура репозиторію

* **Рушій:** Godot Engine 4.x (розробка та тестування у Godot 4.7.2)
* **Мова програмування:** GDScript (100%)
* **Асети:** Kenney Top-Down Assets (CC0) + кастомний стилізований план музею

```text
├── assets/          # Спрайти, тайлсети, стилізований план підлоги музею та шрифти
├── docs/            # Game Design Document (GDD), STATUS.md та GAME_OVERVIEW.md
├── scenes/          # Ігрові сцени Godot (.tscn): рівні, гравець, охоронці, тестова сцена
├── scripts/         # Логіка геймплею, AI (патруль, слух, монетки) та інтерактивних об'єктів (.gd)
├── systems/         # Системні модулі (GameManager, SceneManager, збереження результатів)
├── tests/           # Автоматичні перевірки в Godot та тестові сценарії
├── ui/              # Єдина тема UI, головне меню, HUD, екран паузи та звіт результатів
└── project.godot    # Конфігурація проєкту
```
